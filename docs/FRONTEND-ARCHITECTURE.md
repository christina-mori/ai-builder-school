# 前端结构与接入位置

## 运行模型

当前没有框架、构建器或运行时 npm 依赖。静态服务器以 `dist/` 为根提供文件。路由位于 URL hash 中，所以部署在仓库子目录也不依赖服务端 SPA rewrite。中台用 `/admin/#overview` 等独立路由。

学生端脚本顺序是实现的一部分：

1. `app.js`：基础示例数据、localStorage、通用转义、弹窗与绘制。
2. `learning.js`：领域 / 难度、进阶锦囊与旧交互扩展。
3. 蓝色版额外加载 `bright.js`。
4. `journey.js`：向导、首页场景和旅程数据。
5. `experience.js`：当前 shell、路由、双任务、个人中心、广场、头像、账户与社交演示。
6. `resources.js`：覆盖锦囊目录和详情，建立示例文件的查看 / 下载元数据。
7. `realm.js`：全屏地图及初次渲染。
8. `compare.js`：配色切换、桌面紧凑导航，并包装 render。
9. `onboarding.js`：首次使用指引，再次包装 render 和登录流程。

蓝色版从 `dist/bright/` 加载基础文件快照，之后引用上级共享脚本。不要只修改根目录 `app.js` 就认为蓝色版已经同步。建议接 API 时先建立模块化的数据访问层，再逐步收敛重复文件；无需为交接直接重写整套 UI。

## 学生端数据层

| 位置 | 当前职责 | 接口化时替换 |
|---|---|---|
| `app.js` 的 `storageKey` / `persist()` | `builder-school-demo-v1` 本地存档 | 用户会话、持久化请求、错误处理 |
| `experience.js` 的 `taskCatalog`、`weeks` | 固定任务与周次 | 查询当前期次已发布的课程、周次、任务 |
| `taskRecord()` / `saveMission()` | 网站、知识库草稿与版本 | 草稿、正式提交与版本 API |
| `localSave()` | 内存快照及本地保存失败回滚 | 请求状态、重试、服务端校验、冲突处理 |
| `resources.js` 初始化与 `resourcesPage()` | 示例元数据和筛选 | 读取已发布锦囊，保留后端返回的 URL |
| `communityMembers()` / `saved.social.requests` | 虚构伙伴与本地好友申请 | 真实用户、申请投递与服务端双方授权 |
| `saved.workLikes` | 当前体验档案的 0 / 1 点赞 | 服务端唯一点赞关系与实际总数 |
| `demoAccount`、`finishAuth()` | 固定演示验证码 `123456` | 正式认证；删除演示身份逻辑 |
| `onboarding.js` | 档案中的 `welcomeGuideCompleted` | 明确是否按账号保存，避免误用全站共享状态 |

现有 `saved` 对象中，根部 `draft` / `versions` / `feedback` 属于个人网站任务；`knowledge` 中的同名字段属于知识库任务。它是兼容旧演示记录的结构，不是推荐数据库模型。实际后端应以用户、任务、提交版本等稳定 ID 关联，不依赖数组位置或姓名。

头像在浏览器里裁剪为 256×256 的 data URL；正式接入应上传文件，返回受控资源地址，并在账号间正确隔离。演示账户退出后仍保留本地作品，这不构成任何服务端授权保证。

## 中台数据层

`dist/admin/admin.js` 为独立 IIFE，保存自己的状态和 IndexedDB。`init()` 读取 `builder-school-admin-prototype-v1` / `data` / `state`；`save()` 写整份 state；`mutate()` 负责本地回滚。附件 Blob 也保存在 state 内。

替换这些入口时，需要同时把各表单动作接到分资源 API，增加 loading、失败、重试及版本冲突反馈。不能只把整份 state 上传给后端：服务端需要独立身份、权限、事务、稳定 ID、附件对象与审计记录。

`seed()` 只含演示数据。新后端上线后不得自动将它作为真实学员或作业写入数据库。

## 页面与资源维护

- 静态文件使用相对路径；共享脚本以自身 URL 解析素材，修改后验证根路径和仓库子目录两种情况。
- 字体子集必须随文案更新；用户输入的额外字符使用系统字体回退。
- 图像 WebP 失败时保留 PNG 回退，不能只上传其中一种。
- 桌面完整导航保留文档占位，紧凑导航是独立固定浮层，仅动画 transform / opacity。隐藏的导航使用 inert 和 aria-hidden，避免重复交互入口。
- 手机继续使用底部导航；地图是全屏独立视图。新手指引有独立遮罩和焦点处理。接入时应验证导航、弹窗、地图、指引叠层关系。
- `render()` 会重建页面 DOM，异步请求完成前后要保留表单输入、避免旧请求覆盖新路由，并防止重复提交。

## 代码整理范围
